Static review of the MCP client configuration and of the tool definitions the servers expose (tools/list). Rules are pattern-based and can produce false positives or miss obfuscated payloads; every finding should be confirmed by a reviewer before it is closed or accepted. The audit does not execute tools, inspect server source code or observe runtime behaviour. Text taken from the audited servers is escaped and hidden characters are highlighted; the page's Content-Security-Policy blocks remote loads and any script but its own severity filter.
